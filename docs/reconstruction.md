# Périmètre de la reconstruction

Les états intermédiaires utilisés pour l’import sont des assemblages de fichiers préparés aujourd’hui. Ils ne sont pas des copies originales datées de septembre. Le quatrième état reprend le projet existant, puis les nouveaux livrables sont ajoutés aux dates réelles de leur production. Les résultats techniques se vérifient indépendamment de ces dates attribuées.
